# 新增结果的推导笔记（第十轮，改稿前核对用）

记号同论文：d=2^n，Pauli 信道 N_p(ρ)=Σ_P p_P PρP，惊异度 s(P)=−log₂p_P，
F(u)=P[s<u]。

## A. 随机态码本的信息容量（新定理 2）

设定：M 个码字 ψ_1,…,ψ_M 独立地从同一个系综中抽取，经过 N_p 后由接收方测量，
猜出发送的是哪一个（等先验）。

### A1. 可达性（只需 1-design）

取误差集合 G={P: s(P)<n−a}，Π_i 为 span{P|ψ_i⟩ : P∈G} 上的投影。
用 Hayashi–Nagaoka 平方根测量
E_i=(Σ_jΠ_j)^{−1/2} Π_i (Σ_jΠ_j)^{−1/2}。Hayashi–Nagaoka 不等式（c=1）给出

  1 − tr N(ψ_i)E_i ≤ 2[1 − tr N(ψ_i)Π_i] + 4 Σ_{j≠i} tr N(ψ_i)Π_j。

- 第一项：tr N(ψ_i)Π_i ≥ p(G)，因为每个 P∈G 的像都在 Π_i 的支撑里。
- 第二项：ψ_i 与 Π_j 独立，E ψ_i=I/d 且 N 保持单位，所以
  E tr N(ψ_i)Π_j = tr Π_j/d ≤ |G|/d < 2^{−a}。

于是对码本取平均，

  P_err ≤ 2 P[s ≥ n−a] + 4(M−1) 2^{−a}。                     (A1)

i.i.d. 噪声、M=2^{Rn}：取 a=(R+ε)n，则 n−a=n(1−R−ε)。当 R<1−H−ε 时
P[s ≥ n(1−R−ε)] 指数小，第二项 ≤ 4·2^{−εn}。故任何速率 R<1−H 可达。

### A2. 逆定理（需要 2-design），强逆：速率 > 1−H 时成功率 → 0

对任意测量 {E_i}（ΣE_i=I）和任意 c>0，
tr E_i N(ψ_i) = tr E_i(N(ψ_i) − cI) + c tr E_i ≤ tr(N(ψ_i) − cI)_+ + c tr E_i，
对 i 求和、c tr ΣE_i = cd，所以

  P_succ ≤ cd/M + (1/M) Σ_i tr(N(ψ_i) − cI)_+。

（对固定码本成立，不需要码字独立；取平均时每项的期望相同。）

单态估计：在 p_P > c' 处把 N(ψ) 分成头部 N_h 和尾部 N_t。
- 对 PSD A：tr(A + B − cI)_+ = max_{0≤Q≤I} tr Q(A+B−cI) ≤ tr A + tr(B − cI)_+，
  而 tr N_h(ψ) = m_h = P[s < log₂(1/c')]。
- 对 PSD B 的每个本征值 λ≥0：(λ − c)_+ ≤ λ²/(4c)（因为 (λ−2c)² ≥ 0）。所以
  tr(B − cI)_+ ≤ tr B²/(4c)。
- 2-design：E tr N_t(ψ)² = (d v_t + m_t²)/(d+1) ≤ v_t + 1/d，且 v_t ≤ c' m_t ≤ c'。

记 γ = cd，c' = c 2^{−a}，则 log₂(1/c') = n − log₂γ + a，

  E P_succ ≤ γ/M + 1/(4γ) + 2^{−a}/4 + P[s < n − log₂γ + a]。      (A2)

i.i.d.、M = 2^{nR}：取 γ = 2^{n(R−ε)}、a = εn。四项依次为 2^{−εn}、
2^{−n(R−ε)}/4、2^{−εn}/4、P[s < n(1−R+2ε)]。只要 R > max(1−H, 0) + 2ε（ε>0），
最后一项指数小，E P_succ → 0（指数地）。注意 R > ε 是必需的：M 固定时
P_succ ≥ 1/M 不可能趋于零，此时用旧的单态界 (A3′) 得 P_succ ≤ 1/M + e^{−Ω(n)}。
名称写成“针对打乱（2-design）码本的强逆定理”，不是信道的强逆定理：信道的
经典容量大于 1−H（见 A3）。

(A3′) 单态界（H>1 时 M 固定也适用）：
P_succ ≤ 1/M + (1/M)Σ_i ½‖N(ψ_i) − I/d‖₁，且
E ½‖N(ψ) − I/d‖₁ ≤ P[s<n+a] + 2^{−a/2}/2（因子是 1/2，不是 1/√2）。

逆定理确实需要 2-design：计算基态（1-design）配 p_I=p_z=0.45、p_x=p_y=0.05 时
H≈1.47>1，但 Z 错误对计算基态无作用，信道等价于翻转概率 0.1 的经典比特翻转，
可达速率 1−h₂(0.1)≈0.53>0。

结合 A1：随机 2-design 码本经过 i.i.d. Pauli 信道的可达速率恰好是 max(0, 1−H)，
即 hashing 速率。可达性只需 1-design，逆定理需要 2-design 的二阶矩。

注意：A1 中 HN 不等式的因子 2 使二阶项常数不紧，所以不声称二阶（色散）展开。

### A3. 与乘积态容量的比较

qubit 去极化信道的经典容量 C = 1 − h₂((1+λ)/2)，λ=1−r（King 2003，加性成立，
乘积纯态可达）。它对所有 r<1 都为正。所以在 r_c < r < 1 区间，乘积编码还能传
信息，随机打乱的编码却完全传不了：打乱编码在这个区间付出了全部容量。

引用：去极化可加性 King, IEEE TIT 49, 221 (2003)；单比特单位信道
King, J. Math. Phys. 43, 4641 (2002)。“乘积编码”的准确说法是“乘积纯态输入
加联合（HSW）译码”。

速率 1−H 恰好等于 hashing 量子速率，这是巧合还是必然，笔记里不下结论。

## B. 单层噪声后误差缓解的样本下界（推论）

设一个误差缓解程序用 N 份含噪态 N(ρ) 的拷贝，对所有理想输入 ρ 都以 ≥1−ε 的
概率把 tr(Aρ) 估到 ±δ 以内。若有两个输入 ψ_1, ψ_2 满足 tr A(ψ_1−ψ_2) > 2δ，
则这个程序能以 ≥1−ε 的成功率区分 N(ψ_1)^{⊗N} 与 N(ψ_2)^{⊗N}，所以

  1 − 2ε ≤ ½‖N(ψ_1)^{⊗N} − N(ψ_2)^{⊗N}‖₁ ≤ N · ½‖N(ψ_1) − N(ψ_2)‖₁。

（这正是 Takagi–Tajima–Gu 定理 1 证明里的两点论证。）

取随机对：Markov 不等式给 P[T_pair > 2T̄] ≤ 1/2；2-design 给
E|⟨ψ_1|ψ_2⟩|² = 1/d，故 P[|⟨ψ_1|ψ_2⟩|² > 4/d] ≤ 1/4。两者同时不发生的概率
≥ 1/4，所以存在一对，T_pair ≤ 2T̄ 且 |⟨ψ_1|ψ_2⟩|² ≤ 4/d。取 A=ψ_1（投影），
tr A(ψ_1−ψ_2)=1−|⟨ψ_1|ψ_2⟩|² ≥ 1−4/d，只要 2δ < 1−4/d 即可用。于是

  N ≥ (1 − 2ε) / (2 T̄_n)。                                       (B1)

H>1 时 T̄_n=e^{−Ω(n)}，样本数对 n 指数增长；这只需要**一层**噪声。

对比：Takagi–Tajima–Gu 定理 3 在一层（L=1）时给出 N ≳ (1−2ε)²/(2 ln2 · n(1−γ)²)，
不随 n 指数增长；Quek 等人的纯度路线在一层时只能在 r>0.423 给出指数下界。
H<1 时 T̄_n→1，这条两点论证不给指数下界（但这不证明误差缓解便宜）。

精确假设（论文必须写明）：ε<1/2，d>4；程序对系统的唯一访问是同一个 N(ρ) 的
N 份拷贝（不改电路、不调噪声、不插门、无无噪资源），测量可以联合且自适应；
保证必须对包含全局秩一投影的观测量类（例如所有 ‖A‖≤1）和 2-design 支撑上的
所有纯输入一致成立。只针对某个固定局域观测量的程序不在此范围内。
重叠那一步只需 1-design + 独立。

## C. 空闲存储的保持时间（Pauli twirl 近似）

T₁、T₂ 下空闲 t 时间的 Pauli twirl 近似（Ghosh–Fowler–Geller 式 (10)）：

  p_x = p_y = (1 − e^{−t/T₁})/4，
  p_z = (1 − e^{−t/T₂})/2 − (1 − e^{−t/T₁})/4。

保持时间 t_c 定义为 H(p(t)) = 1 的解。T₂=T₁ 时退化为去极化：
r(t)=1−e^{−t/T₁}，t_c = −ln(1−r_c) T₁ = 0.2909 T₁。纯度能证明丢失的时间：
(1−r)²<1/3 ⇔ t > (ln 3 / 2) T₁ = 0.5493 T₁。

纯退相干（T₁→∞）：p_z(t)=(1−e^{−t/T₂})/2 < 1/2，H=h₂(p_z)<1 对所有有限 t 成立，
故对任意有限存储时间 T̄_n→1（n→∞）。t→∞ 时趋于完全退相干，正是论文里
σ=0 的退化临界点。

Pauli twirl 是近似：真实振幅阻尼不是 Pauli 信道，也不保单位，此时
E tr ΠN(ψ₂)=trΠ/d 不成立。所以存储结果是 twirl 后信道的定理、原信道的近似。
twirl 公式只在 T₂ ≤ 2T₁ 时给出 p_z ≥ 0。纯退相干：固定有限 t 时 T̄_n → 1，但指数
常数随 t 增大趋于零。

## D. 偏置噪声

总错误率 p，偏置 η=p_z/(p_x+p_y)，p_x=p_y=p/(2(η+1))，p_z=pη/(η+1)。
信息谱阈值 H=1；纯度路线可证丢失的条件 2Σp_i²<1（是两端封闭的区间）。
数值见 bias_and_memory 检查脚本。
