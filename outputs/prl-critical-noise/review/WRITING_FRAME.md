# 短稿的论证与术语

这是一篇英文理论研究记录，不是已经通过创新性审查的 PRL 投稿稿。目标 ≤5 页，采用 REVTeX 双栏以便用户审查。

一句话论证：在一个被监测的临界四次软模中，首光子时间的分位数与矩由两个匹配时间区域控制；数值支持该结果，但其强监测动力学核与2003年的已知原子衍射结果精确相同，因此本研究不能据此主张新的量子临界普适性。

| 术语/符号 | 固定含义 |
|---|---|
| first-click time | 在已制备初态上从t=0启动计数，到首次探测的时间 |
| survival probability S | 从启动计数到指定时间没有点击的概率 |
| interarrival time | 连续两个光子之间间隔；本研究没有把它与first click混同 |
| d | 有效监测强度；不是微观κ |
| κ | Dicke裸腔损耗参数，jump=√(2κ)a |
| τ | 软模时间，微观t=(4N)^(1/3)τ |
| u | 边界层时间√d τ |
| K(u) | 与Fedorov et al.2003 Eq84相同的已知核 |
| r | 等待时间矩阶；不用于驱动幅度 |

读者：能检查理论物理推导的科研人员。优先回答结果是什么、为何成立、与旧结果有何重合以及它不足以支持什么。

段落职责：问题与协议 → 矩标度结果 → 冻结和动能边界层推导 → Dicke映射与有限尺寸数值 → Gaussian/经典替代解释 → 正式文献精确对照与创新否决。

证据：确定性无点击传播、网格/步长细化、微观N=16–512和光子截断48/64比较、独立解析核验、JETP原刊逐式阅读。没有实验数据；没有证明完整微观矩的统一尾界；没有声称新的普适类。
