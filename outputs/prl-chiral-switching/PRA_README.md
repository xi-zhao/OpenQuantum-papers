# PRA manuscript and reproducibility package

**Finite-size decay-mode hybridization near a mean-field fold in an open Rydberg ensemble**

Scientific draft dated 2026-10-28; literature and interpretation revised 2026-10-29. The manuscript studies uniform interactions with independent local decay, at Ω/γ=2 and V/γ=10. All quantitative results are finite-size results in the complete permutation-invariant operator space. The gap exponent is not derived from a quasipotential, and a thermodynamic fold-to-EP limit is not established.

## Environment and quick reproduction

The recorded environment is Python 3.13.2 with the versions in `requirements-pra.txt`. The existing environment supplied all dependencies. LaTeX requires REVTeX 4.2, `amsmath`, `amssymb`, `graphicx`, `bm`, and `hyperref`; `latexmk` and `pdflatex` were used. There is no model API, cloud hardware, or network access in these calculations.

Run the following commands from this directory, or the root of an extracted source archive. Numerical commands write their own outputs, so rerun them in a working copy if preserving the archived samples byte-for-byte matters. They never modify the manuscript's scientific claims automatically. Set single-thread linear algebra for consistency:

```bash
export VECLIB_MAXIMUM_THREADS=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
```

Check stored physical signals, recompute the small-N explicit-spin reference and repeat the N=32 step/seed test:

```bash

```

Regenerate all six figures directly from stored evidence:

```bash
python3 code/pra_figures.py
```

## Provenance and limitations

- The N=24 coherence sample predates the switch from fixed bracketing endpoints to a local expanding bracket. The four original root/derivative records predate the final branch-discontinuity guards. All eight reported roots were subsequently back-substituted with the final verifier. Historical samples have not been silently rewritten.
- `mode_stability.json` is the original inline step/seed check. `pra_validate.py --repeat-modes` is its saved reproduction entry point, writing `validation_repeat.json`. The original relative change used the smaller-step vector in the denominator; the new check uses the original-step vector. Their difference is below 5×10⁻¹¹ and does not affect the quoted bound.
- `inputs.json` cites the historical `data/gN.json` source. Its necessary starting values are embedded in `inputs.json`, so the larger exploratory file is not required or bundled.
- The package excludes old manuscripts, failed instanton trajectories, unused preliminary mode scans, literature downloads, and historical aggregate reports. The working research archive retains those files. Current figures use selected raw records and do not depend on the excluded files.
- Float64 residuals and cross-method consistency are numerical evidence, not rigorous forward-error bounds for every nonnormal eigenvalue. Complex-detuning EP tests are local, not a global enumeration. The real-axis continued fraction cannot be used at complex inputs by substituting `2 Re Σ`.
- A requested final independent manuscript review could not start because its model provider returned a monthly quota error. The present delivery includes local mathematical, numerical, and layout checks; it does not claim that this independent review was completed.
