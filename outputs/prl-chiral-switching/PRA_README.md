# PRA manuscript and reproducibility package

**Finite-size decay-mode hybridization near a mean-field fold in an open Rydberg ensemble**

PRA research draft, revised 2026-11-02 (r2) to streamline the main text after integrating the fixed-preparation physical-effect tests. The manuscript studies uniform interactions with independent local decay, at Ω/γ=2 and V/γ=10. Finite-size mode hybridization and residue exchange remain established numerically. The tested complete density signals remain smooth across the narrow mixing window, and the coherence-source peak is not enhanced over independent atoms. Mean field still fails for the complete coherence-source transient. These conclusions concern the stated preparations and time window; the gap exponent is not derived from a quasipotential, and a thermodynamic fold-to-EP limit is not established.

## Environment and quick reproduction

The recorded environment is Python 3.13.2 with the versions in `requirements-pra.txt`. The existing environment supplied all dependencies. LaTeX requires REVTeX 4.2, `amsmath`, `amssymb`, `graphicx`, `bm`, and `hyperref`; `latexmk` and `pdflatex` were used. There is no model API, cloud hardware, or network access in these calculations.

Run the following commands from this directory, or the root of an extracted source archive. Numerical commands write their own outputs, so rerun them in a working copy if preserving the archived samples byte-for-byte matters. They never modify the manuscript's scientific claims automatically. Set single-thread linear algebra for consistency:

```bash
export VECLIB_MAXIMUM_THREADS=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
```

Check stored physical signals, recompute the small-N explicit-spin reference and repeat the N=32 step/seed test:

```bash
python3 -W error code/pra_validate.py --repeat-modes
```

Regenerate the six original figures directly from stored evidence (five were originally in the main text; the spectral-truncation display is now in the SM):

```bash
python3 code/pra_figures.py
```

Regenerate the physical-effect figure and its CSV from frozen records, using a new output name:

```bash
python3 -W error code/physical_effects_figures.py --output-stem physical_effects_reproduction
```

Build both PDFs. The articles use explicit `thebibliography` entries, so `-bibtex-` avoids an unnecessary BibTeX pass over REVTeX's automatically generated notes database:

```bash

```

The dated package manifest hashes the current records and sources. Verify it before overwriting any sample:


## Provenance and limitations

- The N=24 coherence sample predates the switch from fixed bracketing endpoints to a local expanding bracket. The four original root/derivative records predate the final branch-discontinuity guards. All eight reported roots were subsequently back-substituted with the final verifier. Historical samples have not been silently rewritten.
- `mode_stability.json` is the original inline step/seed check. `pra_validate.py --repeat-modes` is its saved reproduction entry point, writing `validation_repeat.json`. The original relative change used the smaller-step vector in the denominator; the new check uses the original-step vector. Their difference is below 5×10⁻¹¹ and does not affect the quoted bound.
- `inputs.json` cites the historical `data/gN.json` source. Its necessary starting values are embedded in `inputs.json`, so the larger exploratory file is not required or bundled.
- The package excludes old manuscripts, failed instanton trajectories, unused preliminary mode scans, literature downloads, and historical aggregate reports. The working research archive retains those files. Current figures use selected raw records and do not depend on the excluded files.
- The physical-effect pilot, failed 64-phase quadrature check, and rejected spectral candidates are included because they document the new controls. One outer point has a separately stored 256-phase correction; its original 64-phase curve is not overwritten. The main-text center and ±w comparisons do not depend on that correction.
- Original mode-character scans reconstruct the high-branch preparation at each detuning. The new physical-effect scans freeze it at each size's crossing; the coherence source uses the same fold seed throughout. These are distinct protocols.
- The first 2026-11-02 revision integrates existing results; r2 removes numerical inventories from the main text and moves missing reference values and the coherence-reduction table to the SM. Neither revision reruns the large-N scans. Historical manifests, archives, and scientific source data are preserved.
- Float64 residuals and cross-method consistency are numerical evidence, not rigorous forward-error bounds for every nonnormal eigenvalue. Complex-detuning EP tests are local, not a global enumeration. The real-axis continued fraction cannot be used at complex inputs by substituting `2 Re Σ`.
- The independent manuscript review blocked by provider quota on 2026-10-28 was completed on 2026-10-30 for the stated finite-size mathematical claims and evidence. It found no verified error affecting those claims. It did not recompute large-N spectra, certify global analytic branches, or review bibliographic novelty. The response extension and review scope are documented in `PRA_RESPONSE_2026-10-30.md`.
