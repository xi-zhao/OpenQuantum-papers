## 新增的推理或边界句（请确认）

下面这些句子不是新数据，而是从文中已有的设计推出来的，但原稿没写。请确认你同意：

- **§4.2 末段**：采样是均匀数的确定性函数，而提取器保证统计距离不超过 ε，所以生成分布与理想采样的差别也不超过 ε（数据处理不等式）。这是标题里「无损」的理论依据。
- **§4.3 威胁模型**：假设攻击者只能观测输出，不能读取池中未消费的比特；池中比特需要像密钥材料一样保护。原稿说「无状态可窃」，但在有缓冲池的设计下这句话并不成立。
- **§5 的三处边界**：
  - 「生成质量对照只覆盖一个提示与一组采样参数」；
  - 「1500 token/s 未计入共享云平台的排队与调度开销」；
  - 「单价远高于专用光子 QRNG」，这一条取自 README 的"诚实的限定"。

### 最小熵独立性核查（未写入正文，可供答复审稿参考）

用 `data/qz03_qrng_raw.json` 粗查了"逐比特独立估计"这个前提：

- 595 对比特中有 12 对的相关系数超出 3/√N 噪声底，最强一对（比特 20 与 33）r = −0.21；
- 35 个比特中有 2 个在 20 条任务之间有显著漂移（χ² 检验，p < 0.001）；
- 相邻 shot 之间没有可测的相关。

按成对联合分布和逐任务估计修正后，最小熵率约降 0.015 bit/bit（漂移约 0.005，成对相关约 0.009）。按 ε = 2⁻¹⁰⁰ 和每块 7000 → 5496 bit 反推，最小熵率需不低于 0.814；保守估计是 0.855，余量 0.041，足以覆盖。这次只看了成对相关，正式结论应以 NIST 官方 800-90B 工具的非 IID 评估为准。
